File format

The first line must name these columns, in any order:

firstName,lastName,...
  • Every column is required, as on the Add Student form.
  • dateOfBirth is yyyy-MM-dd, e.g. 2005-04-12.
  • gender is Male, Female or Other; phone is 10 digits.
  • course must match an existing course name exactly (case does not matter).
  • A row whose email is already used is skipped, so importing the same file twice adds nothing the second time.
  • Put quotes around a value that contains a comma, e.g. "12 Lake Road, Pune".
